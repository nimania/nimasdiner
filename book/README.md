# ساخت و اصلاح PDF کتاب

سازندهٔ این ویرایش در `build.py` است؛ فونت و عکس و جلد نمایشی را از assets می‌خواند. متن فصل‌ها از PDF منبع خصوصی وارد می‌شود و دوباره تایپ یا reflow نمی‌شود. این کد ویرایش علمی یا راستی‌آزمایی ادعاهای کتاب انجام نمی‌دهد.

## ورودی‌ها

- PDF محتوای اصلی ۴۶ صفحه‌ای همان ویرایش، از آرشیو خصوصی مالک؛ آن را در Git قرار ندهید.
- assets/cover.webp، assets/nima-afshar-naderi.webp و دو فونت وزیرمتن موجود در مخزن.
- Python و وابستگی‌های requirements.txt. نسخه‌های دقیق محیط را برای بازتولید پیکسلی در محیط خود ثبت کنید؛ بازه‌ها به‌تنهایی قفل نسخه نیستند.

```bash
python -m pip install -r book/requirements.txt
python book/build.py --source /private/path/source.pdf --output /private/path/handbook.pdf
```

خروجی این ویرایش ۵۲ صفحه است: جلد، عنوان، شناسنامه، راهنمای استفاده، فهرست، ۴۶ صفحهٔ متن و تماس. پوشهٔ tmp/book پیش‌نمایش‌های QA دارد. شمارهٔ فصل‌ها و لینک‌های فهرست و عدد صفحات بر مبنای همان منبع‌اند؛ تغییر تعداد صفحات ورودی نیازمند اصلاح offsets و TOC است. سازنده برای ورودی با تعداد متفاوت متوقف می‌شود.

QR مشاوره به https://t.me/nimaafsharnaderi در شناسنامه و صفحهٔ پایانی است؛ لینک کانال روزانه https://t.me/nimasdiner از آن جداست. معرفی نویسنده و لینک پندار و گروکی‌پدیا در همین دو صفحه آمده‌اند. فایل نهایی جاری و منبع کامل در آرشیو خصوصی مالک نگهداری می‌شوند؛ محل تحویل جاری BOOK_FILE_ID در Script Properties است.

## کنترل پیش از جایگزینی

شناسنامه، صفحهٔ پایانی، فهرست، نخستین صفحهٔ هر فصل و صفحات تغییرکرده را رندر و ببینید. راست‌چینی، شکل درست حروف، نبود overflow، لینک‌های قابل کلیک و اسکن واقعی QR را کنترل کنید. اگر جلد از webp نمایشی استفاده شود، برای چاپ کیفیت آن را جدا بسنجید؛ این خروجی برای PDF دیجیتال تنظیم شده است.

پس از تأیید، همان فایل خصوصی Drive را با ID فعلی به‌روزرسانی کنید؛ مراحل در docs/OPERATIONS.md آمده است. فایل را در assets عمومی یا GitHub Release عمومی بارگذاری نکنید مگر تصمیم محصول صریحاً تغییر کند.
