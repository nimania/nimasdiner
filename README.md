# نیما داینر

صفحهٔ معرفی و دریافت کتاب «مرجع جامع مدیریت رستوران» نوشتهٔ نیما افشارنادری.

نشانی: https://nimania.github.io/nimasdiner/

## انتشار

GitHub Settings → Pages → Source: GitHub Actions. با هر تغییر در main، گردش‌کار Pages اجرا می‌شود. اگر فعال‌سازی خودکار مجوز نداشت، این انتخاب را یک‌بار در تنظیمات انجام دهید و workflow را دوباره اجرا کنید.

## فرم دریافت

فرم HTML با POST مستقیم به FormSubmit ارسال می‌شود؛ پس از ثبت موفق و کنترل ضدربات، کاربر به download.html هدایت می‌شود. نام و ایمیل الزامی و تلفن و زمینهٔ فعالیت اختیاری است. رضایت بازاریابی جداگانه است و پیش‌فرض انتخاب نشده.

**فعال‌سازی یک‌باره:** مالک باید فرم را یک‌بار از صفحهٔ زنده ارسال کند و ایمیل فعال‌سازی FormSubmit در nimania@gmail.com را تأیید کند. پیش از این تأیید، تحویل اطلاعات به ایمیل نهایی نشده است. ایمیل پاسخ خودکار نیز تابع فعال‌سازی و ضدربات سرویس است.

فایل PDF در این ریپوی عمومی و صفحهٔ دانلود در دسترس عمومی‌اند. فرم، قفل امنیتی یا احراز ایمیل نیست؛ اطلاعات مخاطب برای ارتباط با رضایت دریافت می‌شود. هیچ اطلاعات بازدیدکننده‌ای نباید به این ریپو commit شود.

## ویرایش

فایل‌های اصلی index.html، style.css و app.js هستند. کتاب در assets/restaurant-handbook.pdf قرار دارد. بدون build یا وابستگی خارجی اجرا می‌شود؛ فونت وزیرمتن محلی است.
