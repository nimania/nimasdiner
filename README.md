## اجزای پروژه

| مسیر | مسئولیت |
|---|---|
| `index.html`, `style.css`, `app.js` | صفحهٔ معرفی، فرم و هویت بصری |
| `consulting/` | پرونده‌های مشاوره با ذخیرهٔ رمزگذاری‌شدهٔ محلی در مرورگر |
| `app/` | اپ نصب‌شدنی (PWA) «برنامهٔ امروز»: ریلز، پست و استوری روزانه؛ ساخته‌شده با کیت nimasdiner-social |
| `privacy.html`, `download.html` | حریم خصوصی و راهنمای دانلود مستقیم |
| `assets/` | جلد نمایشی، عکس نویسنده، فونت و آیکون |
| `services/delivery/worker/index.js` | سرویس عمومی دریافت، تأیید ایمیل و ارسال PDF به مرورگر |
| `backend/Code.gs` | Apps Script؛ ثبت خصوصی، توکن‌ها و صف ارسال Gmail |
| `backend/tests/flow.cjs` | آزمون سرویس‌های شبیه‌سازی‌شده، بدون ارسال ایمیل واقعی |
| `book/build.py` | ساخت قاب‌ها، شناسنامه، فهرست، تماس و QR دور متن PDF منبع |
| `.github/workflows/pages.yml` | انتشار فقط فایل‌های عمومی صفحه روی GitHub Pages |

## اصل کار

نام و ایمیل → ثبت خصوصی در Google Sheets → دانلود PDF در همان صفحه. تلفن و رضایت برای دریافت خبرهای آینده اختیاری‌اند. سقف روزانهٔ ساختگی از کد حذف شده است؛ تغییرات Google Apps Script و Worker باید مستقلاً از GitHub Pages منتشر شوند. ورود به گوگل برای مخاطب لازم نیست؛ Gmail و Drive فقط پشت سرور استفاده می‌شوند.

PDF کامل، فهرست مخاطبان، خروجی Sheets، محتوای ایمیل‌ها، توکن اختصاصی مخاطبان، رمزها و کلیدها نباید وارد این مخزن عمومی شوند. فایل PDF قدیمی در تاریخچهٔ Git بوده است؛ حذف از نسخهٔ جاری به معنی حذف از تاریخچه نیست.

## بررسی سریع

```bash
node backend/tests/flow.cjs
node --check services/delivery/worker/index.js
```

این مخزن مرجع نگهداری کل پروژه است. انتشار صفحه، انتشار Worker و نسخه‌بندی Apps Script سه عملیات جدا هستند؛ تغییر یک فایل در GitHub به‌تنهایی دو سرویس دیگر را به‌روز نمی‌کند.

## میز مشاوره

صفحهٔ `consulting/` یک ابزار مستقل فارسی برای ثبت گام‌به‌گام ۲۱ پاسخ، چند پرونده، ماشین‌حساب نقطهٔ سربه‌سر و تهیهٔ خروجی است. سایت روی **GitHub Pages عمومی** میزبانی می‌شود، اما اطلاعات ثبت‌شدهٔ مشتری به GitHub، سرور یا Google ارسال نمی‌شود.

**نسخهٔ فعلی بدون ورود و رمز است.** پاسخ‌های مشتری در `localStorage` همان مرورگر و **بدون رمزگذاری** نگهداری می‌شوند. بنابراین هرکس به همان مرورگر و حساب کاربری دستگاه دسترسی داشته باشد ممکن است آن‌ها را ببیند. اطلاعات بین دستگاه‌ها همگام نمی‌شوند؛ پاک‌کردن دادهٔ سایت یا استفاده از مرورگر دیگر باعث ناپدیدشدن پرونده‌ها از آن محیط می‌شود. از گزینهٔ «پشتیبان JSON پرونده‌ها» مرتب خروجی بگیرید و فایل را محرمانه نگهداری کنید. فایل‌های خروجی TXT و JSON رمزگذاری نشده‌اند. این نسخه جایگزین سرویس ابری با احراز هویت نیست.

برای جلوگیری از ازدست‌رفتن داده‌های پیشین، `consulting/legacy.html` همچنان نسخهٔ قبلیِ رمزگذاری‌شده را با کد `consulting/consulting.js` اجرا می‌کند. دادهٔ قدیمی در کلید مجزای `nimasdiner_consulting_encrypted_v1` باقی می‌ماند. کاربر برای بازیابی آن باید رمز قبلی را وارد کند و سپس برای هر پروندهٔ موردنیاز خروجی JSON بگیرد و در نسخهٔ بدون رمز وارد کند. نسخهٔ بدون رمز از کلید مستقل `nimasdiner_consulting_local_v2` استفاده می‌کند و هیچ دادهٔ قبلی را پاک نمی‌کند.
