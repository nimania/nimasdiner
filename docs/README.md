# راهنمای ادامهٔ کار

آخرین مستندسازی: ۲۰۲۶-۱۰-۲۶. وضعیت‌ها را پیش از هر عملیات از سرویس زنده بررسی کنید؛ دادهٔ مخاطبان در این اسناد نگهداری نمی‌شود.

1. برای فهم مسیر و دلیل انتخاب‌ها: [معماری](ARCHITECTURE.md).
2. برای تغییر، انتشار، تعویض کتاب و بازیابی: [عملیات](OPERATIONS.md).
3. برای معنی ستون‌ها، رضایت و شمارش دریافت: [داده‌ها](DATA.md).
4. برای خطای مخاطب، ایمیل و صف: [عیب‌یابی](TROUBLESHOOTING.md).
5. برای ساخت PDF: [کتاب](../book/README.md).

## قواعد محصول

- زبان فارسی، راست‌به‌چپ، فونت وزیرمتن؛ رنگ زرد خردلی، ذغالی، قرمز محدود و شطرنجی داینر.
- جلد و متن موجود مبنا هستند؛ اصلاح ظاهر نباید متن فصل‌ها را بی‌خبر تغییر دهد.
- نام و ایمیل اجباری؛ تلفن، نقش، موقعیت، شهر، کشور، نوع رستوران و اینستاگرام اختیاری.
- رضایت خبرهای آینده جدا، اختیاری و پیش‌فرض خاموش است؛ ارسال همین کتاب بخشی از درخواست مخاطب است.
- هیچ نمونهٔ عمومی از صفحات کتاب نمایش داده نمی‌شود؛ نسخهٔ کامل پس از تأیید ایمیل تحویل می‌شود.

## محدودهٔ پوشش

کد اجرایی Worker، Apps Script، آزمون‌ها و سازندهٔ PDF نگهداری شده‌اند. حساب‌ها، تنظیمات مالک، مجوز OAuth، محرمانه‌های آینده و متن PDF منبع باید جداگانه در اختیار نگهدارندهٔ مجاز باشند. سورس کامل کتاب در مخزن عمومی قرار نمی‌گیرد.
