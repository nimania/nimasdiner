# نیما داینر — هسته توسعه‌پذیر سایت

وضعیت: شاخهٔ آزمایشی؛ انتشار روی main پس از بررسی. این تغییر **دادهٔ مخاطبان را منتقل یا حذف نمی‌کند**.

## قرارداد حفظ دریافت کتاب
- مسیر جدید: \`/nimasdiner/get-book/\`.
- فایل \`content/get-book-form.html\` نسخهٔ عیناً نگهداری‌شدهٔ فرم اصلی است.
- مقصد POST همان \`https://nimasdiner-delivery.iran.chatgpt.site/register\` است.
- نام فیلدها، honeypot، رضایت اختیاری، کد \`app.js\` و سرویس Worker/Apps Script/Sheets تغییر نمی‌کنند.
- صفحهٔ اصلی همچنان \`#get-book\` دارد، اما برای خود فرم به مسیر مستقل می‌فرستد.
- دربارهٔ تعداد صفحات PDF در فرم عددی اعلام نمی‌شود چون ممکن است نسخهٔ پشت سرویس فعلی هنوز قدیمی باشد؛ نسخهٔ نهایی را پیش از تغییر Drive تأیید کنید.

## افزودن کتاب یا شمارهٔ مجله
\`content/catalog.json\` مرجع دادهٔ عمومی است:
- \`books[]\`: شماره \`n\`، وضعیت \`status\`، عنوان، توضیح و در صورت انتشار سرفصل و تعداد صفحه؛
- \`magazines[]\`: شمارهٔ ترتیبی، عنوان تک‌موضوعی، سرفصل‌ها، وضعیت؛
- \`guides[]\`: محتوای کوتاه HTML-ساز (عنوان‌ها و پاراگراف‌ها)، آدرس ثابت و کلیدواژه‌ها.

برای جلدهای پیشنهادی \`status: "planned"\` بگذارید. **پیش‌نمایش عنوان‌های برنامه‌ریزی‌شده در کتابخانه وجود دارد ولی صفحهٔ مستقل و نشانی قابل ایندکس تولید نمی‌شود.** پس از تدوین نهایی، راستی‌آزمایی و تصویب، مقدار را \`published\` کنید.

مجله شماره‌های منتشرنشده را نشان نمی‌دهد و شماره‌ها بر پایه انتشار واقعی جلو می‌روند.

## ساخت سایت
\`\`\`bash
node tools/build-site.mjs
node tools/test-site.mjs
\`\`\`
خروجی تنها در \`site-dist/\` ساخته می‌شود و از طریق GitHub Pages منتشر خواهد شد. برای افزودن محتوا نیازی به ویرایش دست‌نویس ده‌ها فایل HTML نیست. ابزار جست‌وجوی داخلی با \`search-index.json\` بر مبنای صفحات منتشرشده کار می‌کند. نقشه سایت و canonical نیز خودکارند.

## نظرها و عضویت
- **کامنت عمومی هنوز فعال نیست.** در ۸ نوامبر ۲۰۲۶ GitHub Discussions مخزن غیرفعال است و کاربران داینر نباید برای نظر دادن ملزم به داشتن حساب GitHub باشند.
- نسخهٔ فعلی صرفاً لینک ارسال نظر به تحریریه دارد؛ آن را با بخش عمومی کامنت اشتباه نگیرید.
- برای نسخهٔ بعدی: ورود با کد/لینک ایمیل، پایگاه دادهٔ خصوصی، پروفایل کاربر و نظر با وضعیت \`pending/approved/rejected\`، ضداسپم، حذف/ویرایش، گزارش سوءاستفاده، محدودیت ارسال و قابلیت \`noindex\` برای محتوای کاربری آسیب‌زا.
- اطلاعات بیش از ۵۰۰ دریافت‌کنندهٔ کتاب **به‌صورت خودکار حساب فعال یا رضایت به خبرنامه نمی‌شوند**. پس از احراز مالکیت ایمیل و انتخاب داوطلبانه عضو شوند. تفکیک \`downloaded\`، \`email_verified\`، \`member_active\`، \`marketing_opt_in\` ضروری است.
- داده‌های محرمانه مشاوره و ژورنال در GitHub Pages/مخزن عمومی ذخیره نشوند. نسخه فعلی \`consulting/\` ذخیرهٔ بدون رمز در همان مرورگر دارد.

## سئو و تحقیق تخصصی
- URL پایدار، HTML قابل ایندکس، توضیح منحصربه‌فرد، مسیر راهبری، لینک داخلی، \`sitemap.xml\` و \`robots.txt\`.
- JSON-LD با نوع \`Book\` / \`CreativeWork\` / \`Article\` فقط برای صفحات واقعی؛ تاریخ انتشار و مجوزهای قانونی اختراع نشوند.
- صفحهٔ \`search/\` از ایندکس حذف شده تا نتیجه‌های پرس‌وجو محتوای کم‌ارزش ایجاد نکنند.
- مقاله‌های مقررات، بهداشت، اماکن، دوربین و تکالیف اقتصادی بدون منبع رسمی تاریخ‌دار نباید دستورالعمل قطعی تلقی شوند.
- هر نوشته باید منبع، ویرایش، بازبینی تخصصی و صاحب مسئول مشخصی داشته باشد. در مرحله بعد این فراداده به مدل راهنما اضافه شود.

## راه‌اندازی ایمن
1. PR را بررسی و گزارش CI را تأیید کنید؛ فرم را روی موبایل و بدون ورود گوگل آزمایش کنید.
2. در محیط عملیاتی و با یک ایمیل تست، فرم \`/get-book/\` و دانلود واقعی را بررسی کنید.
3. بعد از ادغام با main، وضعیت Pages، sitemap و نتایج Search Console را کنترل کنید.
4. اطلاعات مخاطبان، PDF خصوصی و سرویس تحویل کتاب دست‌نخورده می‌مانند.
